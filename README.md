
Requisitos de funcionamiento

    -Java 17 o superior
    -Apache Maven

Configuracion de la dificultad

    La dificultad se puede modificar en la clase Principal.java en la linea (27) int dificultad = 3.
    Modificando el valor 3 podemos probar la dificultad que queramos siempre y cuando este comprendida
    entre los valores 1 y 64.

Compilar el programa
    
    Para compilar el programa podemos utilizar el Entorno de Desarrollo Apache NetBeans usando la opcion 
    Clean and Build del propio IDE. 

    Para su ejecucion de igual manera podemos utilizar la herramienta de ejecucion de Apache NetBeans.

    El programa va a solicitar al usuario una semilla inicial y la ruta del archivo de texto que contiene
    los bloques.
    
    El archivo por defecto que contiene los bloques de prueba se llama bloques.txt y esta situado en la 
    carpeta del proyecto al mismo nivel que el pom.xml
